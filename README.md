# ReForge

ReForge is a team project building a shared game engine for two ideas: a dungeon crawler and a cybersecurity-themed game module. We’re exploring which systems both can reuse and how each can keep its own gameplay.

## What we’re building

| Component | Focus |
| --- | --- |
| **Shared Engine** | Common game systems and tools that both modules can build on. |
| **Dungeon Crawler** | A game module centered on dungeon exploration. |
| **Cybersecurity Module** | A game module that explores cybersecurity concepts through gameplay. |

## Project status

**In progress.** We’re setting up the shared engine and defining how each module will build on it.
